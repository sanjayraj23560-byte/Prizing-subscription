## 🛠 Technical Highlights
- **Flexbox & Grid:** Used to create perfectly aligned, equal-height pricing cards.
- **Glassmorphism UI:** Implemented using `backdrop-filter: blur()` and semi-transparent RGBA backgrounds for a sleek, modern aesthetic.
- **Hover Interactions:** CSS pseudo-classes (`:hover`, `:scale`) provide instant visual feedback to users.
- **Responsive Design:** Utilized CSS Media Queries to transition from a 3-column desktop view to a 1-column mobile-friendly stack.

## 📂 Architecture
- `index.html`: Semantic structure using `<section>` for the container and `<article>` for individual pricing tiers.
- `style.css`: Custom properties (CSS Variables) for easy color theme management.
